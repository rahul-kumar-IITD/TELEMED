# E4-S1: Doctor can append consultation notes that patients can read

- Epic: E4 (Records and Administration)
- Layer: API
- Group: I
- Estimate: M
- Depends on: E3-S5
- Brief criteria covered: AC-09, NFR-02, NFR-03, NFR-08

## Description

After an appointment is COMPLETED its doctor appends free-text notes (up to 5000 characters). Notes are never editable or deletable and are readable only by the patient, the doctor and admins. No note content may appear in logs.

## Acceptance Criteria

1. The appointment's doctor can POST /api/appointments/{id}/notes {text} after COMPLETED, receives 201 each time, and multiple notes accumulate.
2. Adding a note to an appointment that is not COMPLETED returns 409; another doctor receives 404 and a patient receives 403.
3. A note of 5000 characters is accepted, while 5001 characters or empty text returns 422.
4. PUT, PATCH and DELETE on a note return 405, and a direct SQL UPDATE or DELETE on consultation_notes is rejected by the trigger.
5. GET notes returns 200 to that appointment's patient, its doctor and an admin, and 404 to a different patient or a different doctor.
6. Posting a note logs the appointment_id and user_id but never the note text.
