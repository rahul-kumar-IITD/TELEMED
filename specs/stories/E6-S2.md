## Description

Automated gates that the grader and CI use: coverage thresholds, import-linter layer contract, strict typing and lint, and a check that every acceptance criterion AC-01 to AC-10 and every NFR-01 to NFR-08 has at least one tagged test.

## Acceptance Criteria

1. `uv run pytest --cov` fails when overall coverage is below 80% or domain-layer coverage is below 95%.
2. A traceability check reports at least one test tagged for each of AC-01 through AC-10 and exits non-zero when any is missing.
3. `uv run lint-imports` passes on the repository and fails when a Repository module imports a Service module.
4. `uv run mypy --strict src/` and `uv run ruff check .` report zero errors.
5. The traceability check also reports at least one test tagged for each of NFR-01 through NFR-08 and exits non-zero when any is missing.
