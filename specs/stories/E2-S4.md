# E2-S4: Patient can search doctors and view open slots

- Epic: E2 (Providers and Availability)
- Layer: API
- Group: E
- Estimate: M
- Depends on: E2-S2
- Brief criteria covered: AC-02, AC-03

## Description

Patients search active doctors by specialty, language and availability range, sort the results, and open a doctor to see the real open slots for the next 14 days. Fees are visible before booking.

## Acceptance Criteria

1. GET /api/doctors?specialty=Cardiology returns only doctors with that specialty, and ?language=hi returns only doctors who speak that language.
2. GET /api/doctors?available_from=&available_to= returns only doctors with at least one AVAILABLE slot inside the range.
3. The sort parameter orders results ascending by earliest open slot, by fee, or by name.
4. Each result includes the fee as a string such as "500.00" and the earliest open slot, and deactivated doctors never appear.
5. GET /api/doctors/{id}/slots lists only AVAILABLE slots starting after now and within 14 days; BOOKED, BLOCKED and past slots are never listed.
6. Unauthenticated calls to the search and slot endpoints return 401.
