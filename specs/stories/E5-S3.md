# E5-S3: Patient UI for my appointments, notes and profile

- Epic: E5 (Frontend Experience)
- Layer: UI
- Group: J
- Estimate: L
- Depends on: E5-S2, E4-S3, E4-S1, E3-S4, E1-S5
- Brief criteria covered: AC-01, AC-06, AC-07, AC-09

## Description

Patient screens for My appointments with cancel and reschedule, read-only consultation notes, the video join link and profile editing. Server remains authoritative; the UI handles 409 gracefully.

## Acceptance Criteria

1. My appointments lists each appointment with a status text label, and shows a 'Join video visit' control only for BOOKED, CHECKED_IN and IN_PROGRESS.
2. Inside the last 60 minutes before start, Cancel and Reschedule are disabled with a visible explanation; outside it they are enabled.
3. Confirming cancel updates the card to CANCELLED, and a 409 response shows an inline message instead.
4. Reschedule lets the patient pick another open slot of the same doctor and the card then shows the new time.
5. The consultation notes view for a completed appointment lists notes read-only with no edit or delete controls.
6. The profile form saves changes, shows a success message, and re-loading the page shows the saved values.
