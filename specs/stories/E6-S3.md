# E6-S3: End-to-end and component tests cover the main flows at both viewports

- Epic: E6 (Seed, Quality Gates and E2E)
- Layer: UI
- Group: K
- Estimate: L
- Depends on: E5-S3, E5-S4, E5-S5, E6-S1

## Description

Playwright projects for desktop (1280) and mobile (375) with fixed timezone and clock, covering the three role flows with screenshot baselines, plus vitest component tests for the behaviours specified in the BRD. The frontend testing plan is an assistant proposal pending user approval.

## Acceptance Criteria

1. playwright.config defines a desktop project at 1280px and a mobile project at 375px, both with a fixed timezone and a fixed clock.
2. The patient flow of search, pick slot, book, view in My appointments, then cancel or reschedule passes on both projects.
3. The doctor flow of daily queue status changes, NO_SHOW disabled before start, and adding a note after COMPLETED passes on the desktop project.
4. The admin flow of onboarding a doctor and deactivating then reactivating a user passes on the desktop project.
5. Screenshot baselines are committed for each key screen at both viewports, and `npm test` vitest component tests pass for the 60-minute disabled state, allowed-actions buttons, 409 handling, 401 redirect, not-found page and sessionStorage token.
