# E2-S1: Slots are generated idempotently from availability templates

- Epic: E2 (Providers and Availability)
- Layer: Service
- Group: B
- Estimate: L
- Depends on: E1-S1, E1-S2
- Brief criteria covered: AC-03

## Description

A zone-aware slot generator expands each doctor's weekly availability template into AVAILABLE slots stored in UTC, only inside the window now < start < now + 14 days. It runs at onboarding, in the seed script and at app startup, and never produces duplicates.

## Acceptance Criteria

1. A template of Monday 09:00-12:00 with 30-minute slots yields exactly 6 AVAILABLE slots for each Monday in the next 14 days.
2. Slots are created only when now < start < now + 14 days; a slot starting in the past or 14 days or more ahead is never created.
3. Running the generator twice produces the same slot count and no duplicate (doctor_id, start) rows.
4. With PROVIDER_TIMEZONE=Asia/Kolkata, a 09:00 template time is stored as 03:30 UTC.
5. Starting the app after the clock advanced 5 days creates the slots for the newly in-window days without duplicating existing ones.
