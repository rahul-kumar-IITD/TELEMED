# E6-S1: Seed script creates synthetic demo data

- Epic: E6 (Seed, Quality Gates and E2E)
- Layer: Service
- Group: G
- Estimate: S
- Depends on: E2-S2, E3-S2

## Description

An idempotent seed script creates an admin, several doctors, several patients and their slots (through the slot generator) so the app can be demonstrated. All data is synthetic and visibly marked as such.

## Acceptance Criteria

1. Running the seed script on an empty database creates 1 admin, at least 3 doctors with distinct specialties and at least 5 patients.
2. Running the seed script twice creates no duplicate users or slots.
3. Every seeded email ends with '@example.test' and seeded slots exist only for the next 14 days via the slot generator.
