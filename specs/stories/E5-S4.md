# E5-S4: Doctor UI for daily queue, slot calendar and notes

- Epic: E5 (Frontend Experience)
- Layer: UI
- Group: J
- Estimate: L
- Depends on: E5-S1, E3-S5, E2-S3, E4-S1
- Brief criteria covered: AC-08, AC-09

## Description

Doctor screens, designed 1280px-first: the daily queue with status actions driven only by allowed_actions, the slot calendar with block and unblock, and the appointment detail with append-only notes. Times show in the provider timezone with its label.

## Acceptance Criteria

1. The queue has a date picker and lists appointments with times in the provider timezone including its label.
2. Each queue row shows only the action buttons listed in allowed_actions, and Mark NO_SHOW is disabled with an explanation before the start time.
3. Clicking a status action updates the row on success, and a 409 shows an inline message and refreshes the queue.
4. The slot calendar can block an AVAILABLE slot and unblock a BLOCKED slot, and BOOKED slots have the block control disabled.
5. The appointment detail shows an add-note form only when COMPLETED and lists existing notes with no edit or delete controls.
6. At 1280px the doctor screens use the full layout, and at 375px they show no horizontal scroll.
