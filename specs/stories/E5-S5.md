# E5-S5: Admin UI for doctor onboarding and user management

- Epic: E5 (Frontend Experience)
- Layer: UI
- Group: H
- Estimate: M
- Depends on: E5-S1, E2-S2, E4-S2
- Brief criteria covered: AC-10, AC-01

## Description

Admin screens, designed 1280px-first: an onboarding form with availability template rows, and a user list with deactivate, reactivate and patient profile editing.

## Acceptance Criteria

1. The onboarding form collects specialty, languages, fee and one or more template rows (weekday, start, end, slot length), and success shows the new doctor.
2. Server 422 template errors are displayed next to the offending fields and the form keeps the entered values.
3. The user list supports a role filter and shows Deactivate or Reactivate per user, with Deactivate disabled on the admin's own row.
4. A 409 on deactivating a doctor shows a message stating the doctor has active appointments, and the status is unchanged.
5. Edit profile on a patient row opens a form that saves and shows a success message.
