# E4-S3: Patient can list and open their own appointments

- Epic: E4 (Records and Administration)
- Layer: API
- Group: I
- Estimate: M
- Depends on: E3-S5, E3-S4
- Brief criteria covered: AC-04, AC-09

## Description

Patients see their appointments with status, fee, allowed actions and a video join link while the appointment is active. Allowed patient actions respect the 60-minute rule. Doctors and admins can open appointment detail within their access.

## Acceptance Criteria

1. GET /api/appointments/mine returns only the caller's appointments ordered by start time, each with status, fee string, doctor name and allowed_actions.
2. GET /api/appointments/{id} for another patient's appointment returns 404, for the appointment's own doctor or an admin returns 200.
3. For a patient, allowed_actions includes CANCEL and RESCHEDULE when start minus now is at least 60 minutes and excludes both inside that window.
4. join_url is non-null for the patient and the doctor while the status is BOOKED, CHECKED_IN or IN_PROGRESS, and null for COMPLETED, CANCELLED and NO_SHOW.
