# E2-S3: Doctor can view, block and unblock their own slots

- Epic: E2 (Providers and Availability)
- Layer: API
- Group: E
- Estimate: M
- Depends on: E2-S2
- Brief criteria covered: AC-03

## Description

Doctors manage their slot calendar. They can block an AVAILABLE slot and unblock a BLOCKED slot, but never block a booked slot or touch another doctor's slots. All transitions are single conditional updates.

## Acceptance Criteria

1. GET /api/doctors/me/slots?from=&to= returns only the caller's slots in the range with their status.
2. PUT /api/doctors/me/slots/{id}/block on an AVAILABLE slot returns 200 and the slot becomes BLOCKED.
3. Blocking a BOOKED slot returns 409 and the slot and its appointment remain unchanged.
4. PUT /api/doctors/me/slots/{id}/unblock on a BLOCKED slot returns 200 and the slot becomes AVAILABLE, while unblocking a non-BLOCKED slot returns 409.
5. A doctor blocking another doctor's slot receives 404 and a patient calling the block route receives 403.
