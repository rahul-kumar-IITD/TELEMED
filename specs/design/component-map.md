## Layering rule applied to every `B/api/*` file above
`B/api/*` imports only `B/service/*` and `B/types/*`, never `B/repository/*` or `B/config/*` (import-linter `forbidden` contract in `backend/pyproject.toml`, wired in E6-S2). Rows above that say an API file "uses" repository data do so through the named service module.

## Cross-cutting files (not owned by one story)
- `B/api/app.py`: touched by E1-S2, E1-S3, E2-S1 and every router-adding story (router registration only; keep it a thin list).
- `.env.example`: touched whenever a setting is added (E1-S2, E1-S3 JWT_SECRET, E3-S1 VIDEO_BASE_URL).
- `.github/workflows/ci.yml`, `infra/*`: created by `/deploy` (see `deployment.md`), gates wired in E6-S2.
